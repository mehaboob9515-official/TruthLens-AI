🛡️ About TruthLens AI

TruthLens AI is an AI-powered news verification platform. It helps users identify whether news articles are Real or Fake using Machine Learning and Natural Language Processing.


🚀 Main Features

  • AI Fake News Detection
  • URL News Analysis
  • AI Article Summary
  • Trust Score
  • Evidence Verification
  • Source Credibility
  • Sentiment Analysis
  • Dashboard & Charts
  • History & PDF Export

🛠 Technologies Used

Python • Flask • Scikit-learn • SQLite • NLP • TextBlob • Newspaper3k • Chart.js • HTML • CSS
