# TruthLens AI

TruthLens AI is an AI-powered news analysis web application designed to help users evaluate news articles and identify possible misinformation.

## Features

- AI-based Real News / Fake News prediction
- Confidence score
- Trust Score
- Source credibility checking
- Evidence and related-news checking
- Article summarization
- Keyword extraction
- Named Entity Recognition
- Sentiment analysis
- Suspicious-word highlighting
- Latest News feed
- User registration and login
- User-specific analysis history
- Analytics dashboard
- Evidence Articles section
- PDF report export
- Excel report export
- Responsive web interface
- Custom 404 and 500 error pages
